# Use techne

These guides are for operators installing and running the `techne` command-line interface. They cover the CLI-facing workflow; Techne Harness owns controller deployment, runtime architecture, and infrastructure internals.

## Start here

- [Install techne from a checkout](installing.md) — create or repair the currently supported local launcher and manual.
- [Authenticate techne with AWS](authenticating.md) — inspect effective configuration, validate an existing session, and recover an expired IAM Identity Center session.
- [Operate the Techne controller](operating.md) — run offline diagnostics, check local and AWS readiness, inspect the configured controller, and open a bootstrap session.

Use `techne --help` or the installed [`techne(1)` manual](../../../man/techne.1) for the complete command and option reference. No public release or Homebrew package is available yet.
