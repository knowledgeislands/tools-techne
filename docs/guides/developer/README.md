# Develop tools-techne

`tools-techne` does not yet contain an executable, installer, test suite, CI workflow, version marker, changelog, completion output, or manual. Treat it as a pre-implementation scaffold, not a releasable tool.

- [Definition of done](definition-of-done.md) defines the minimum repository and product evidence required as the tool is established.
- [Release tools-techne](releasing.md) defines the prerequisites and ownership boundaries for the first and subsequent releases.
